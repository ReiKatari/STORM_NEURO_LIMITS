<h1 align="center">STORM NEURO LIMITS</h1>

## **О проекте**
STORM NEURO LIMITS — контроллер и панель управления аппаратными и контекстными лимитами при работе с локальными и удаленными нейросетями (LLM, генерация изображений, эмбеддинги). Контролирует распределение VRAM, квантование, температуру и нагрузку на видеокарту.

## **Происхождение и форки**
Оригинальная разработка в рамках экосистемы STORM SOFT.

## **Технологический стек**
- **Языки программирования**: TypeScript, Python, Node.js
- **Интерфейс**: React, Tailwind CSS, Electron
- **Интеграции**: NVIDIA NVML API, Ollama API, Llama.cpp Server, PyTorch VRAM Monitor

## **Ключевые возможности**
- **Динамическое управление VRAM**: Предотвращение вылетов Out of Memory (OOM) при загрузке больших моделей.
- **Мониторинг энергопотребления и температур**: Графики нагрева и нагрузки GPU в процессе инференса.
- **Тюнинг параметров генерации**: Удобная настройка контекстного окна, температуры, top_p и системных промптов.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64, NVIDIA CUDA / AMD ROCm)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_NEURO_LIMITS_<версия>_Setup.exe` или архив `STORM_NEURO_LIMITS_<версия>.zip` из раздела **Releases** на GitHub.
2. Запустите установку.
